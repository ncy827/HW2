# HW2: Q-learning 與 SARSA 演算法之比較研究 — 懸崖尋路 (Cliff Walking)

## 📋 專案說明
本作業旨在透過經典的「懸崖尋路」（Cliff Walking）環境，實作並深入比較兩種強化學習演算法：**Q-learning** 與 **SARSA**。透過相同的環境參數設定，分析其在策略選擇、收斂特性及訓練穩定性上的差異。

---

## 🏗️ 環境描述
本實驗採用 4 × 12 的矩形網格世界（Gridworld）：
*   **起點 (Start)**：左下角。
*   **終點 (Goal)**：右下角。
*   **懸崖 (Cliff)**：起點與終點之間的底部區域。
*   **獎勵機制**：
    *   每移動一步：**-1**。
    *   掉入懸崖：**-100**，且代理人（Agent）會立即回到起點。
*   **結束條件**：成功抵達終點。

---

## ⚙️ 演算法參數
為了確保公平比較，兩演算法使用相同的參數設定：
*   **學習率 ($\alpha$)**：0.1
*   **折扣因子 ($\gamma$)**：0.9
*   **探索策略**：$\epsilon$-greedy ($\epsilon = 0.1$)
*   **訓練回合數**：500 Episodes
